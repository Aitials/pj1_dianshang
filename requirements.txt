# 本文件为重建虚拟环境用的依赖清单（uv / pip 均可用）。
#
# 相对上一版的三处改动，原因如下：
# 1. 移除 zhipuai==2.1.5.20250825
#    它与 zai-sdk 在 PyJWT 上约束互斥：zhipuai 要求 pyjwt>=2.8.0,<2.9.0，
#    zai-sdk 要求 pyjwt>=2.9.0,<3.0.0，两者交集为空。pip 曾靠"先装后升级"
#    侥幸共存（pip check 报错），但 uv 是严格解析器，同一份清单里放两个必然失败。
#    原先由 zhipuai 承担的 chat 调用改由 langchain-openai 接管。
# 2. PyJWT 由 2.8.0 改为 2.14.0
#    满足 zai-sdk 的 >=2.9.0，且与当前验证可用的环境一致。
#    注意：PyJWT 只是传递依赖，本项目的鉴权用的是 python-jose，不读 PyJWT。
# 3. 新增 langchain-openai==1.6.7
#    智谱提供 OpenAI 兼容端点，用 ChatOpenAI(base_url=...) 替代 ZhipuAI 客户端。
#    刻意不装 langchain 主包：它会硬拉 langgraph 整套编排栈（26 个包）。
#    将来若确实要用 v1 的 create_agent，再单独加 langchain。
#
# 注意：切换清单后 app/services/AI.py 仍 import zhipuai，需同步迁移，
#       否则后端会在 import 阶段崩溃（见下方说明）。
